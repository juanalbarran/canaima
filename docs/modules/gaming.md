# Gaming

One file per feature under `modules/gaming/`, merged into the `gaming` modules. The NixOS one is imported by `canaima` only (Steam needs the NixOS side for 32-bit graphics, udev rules and firewall ports, so `mucuchies` doesn't get it); the Home Manager one by both `canaima` and `mucuchies`.

- `steam`: Steam with Remote Play and LAN game transfers open in the firewall, GE-Proton as an extra compatibility tool and protontricks. GameMode for `gamemoderun %command%` in a game's launch options.
- `wow`: World of Warcraft. A `whitemane` command (also in the app menu as _WoW Whitemane_) that downloads Whitemane's official launcher AppImage into `~/Games/whitemane` on first run and starts it with `appimage-run`; the launcher downloads and patches the client, and Frozen Throne is picked in it. `programs.appimage` (with binfmt, WebKitGTK and libayatana-appindicator for the Tauri launcher) runs AppImages on NixOS. Wine staging (32 and 64-bit), winetricks and umu-launcher (Proton outside Steam, which the launcher uses to run the client) are installed for the client; the launcher's FHS environment gets a `umu-run` wrapper that sets `PROTONPATH` to the Nix GE-Proton (the launcher asks for `GE-Proton`, which makes umu download the latest from GitHub) and `UMU_RUNTIME_UPDATE=0`, so umu keeps the installed Steam Runtime instead of redownloading it on every launch (Steam's mirrors report different latest versions), and `PROTON_USE_WINED3D=1`, because Haswell's incomplete hasvk Vulkan is rejected by DXVK and the client's native D3D9 fallback is Proton's DXVK `d3d9.dll`, so the client exited with code 3; WineD3D renders over OpenGL. The launcher logs to `~/.local/share/gg.whitemane.launcher/logs/`.
- `lutris` (Home Manager): Lutris, which installs Battle.net for retail WoW (WoW forever) through its own Wine/DXVK runners. Games and the library live outside the store (`~/Games/battlenet`, `~/.local/share/lutris`), so they survive reinstalls. Off NixOS, a `non-nixos-gpu-32-setup` command (run once with `sudo`, and again after driver updates) installs `non-nixos-gpu-32.service`, which links 32-bit Mesa to `/run/opengl-driver-32` and keeps it from being garbage-collected: Home Manager's `targets.genericLinux.gpu` only links the 64-bit drivers, and 32-bit Windows programs like `Battle.net-Setup.exe` fail to create a Vulkan instance without them. Activation warns when the link is missing or outdated.
