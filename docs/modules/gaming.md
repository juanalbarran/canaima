# Gaming

One file per feature under `modules/gaming/`, merged into the `gaming` module. NixOS only, imported by `canaima` (Steam needs the NixOS side for 32-bit graphics, udev rules and firewall ports, so `mucuchies` doesn't get it).

- `steam`: Steam with Remote Play and LAN game transfers open in the firewall, GE-Proton as an extra compatibility tool and protontricks. GameMode for `gamemoderun %command%` in a game's launch options.
- `wow`: World of Warcraft. A `whitemane` command (also in the app menu as _WoW Whitemane_) that downloads Whitemane's official launcher AppImage into `~/Games/whitemane` on first run and starts it with `appimage-run`; the launcher downloads and patches the client, and Frozen Throne is picked in it. `programs.appimage` (with binfmt, WebKitGTK and libayatana-appindicator for the Tauri launcher) runs AppImages on NixOS. Wine staging (32 and 64-bit), winetricks and umu-launcher (Proton outside Steam, which the launcher uses to run the client) are installed for the client; `whitemane` sets `PROTONPATH` to the Nix GE-Proton so umu doesn't download its own, and `UMU_RUNTIME_UPDATE=0` so umu keeps the installed Steam Runtime instead of redownloading it on every launch (Steam's mirrors report different latest versions). Lutris installs Battle.net for retail WoW (WoW forever).
